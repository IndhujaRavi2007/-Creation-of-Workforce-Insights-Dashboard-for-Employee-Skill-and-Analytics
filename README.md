# -Creation-of-Workforce-Insights-Dashboard-for-Employee-Skill-and-Analytics
**Live Demo:** https://ai-powered-workforce-management.vercel.app/login
## 📌 Project Statement
This project focuses on developing an AI-Powered Workforce Analytics & Talent Intelligence Dashboard that enables organizations to gain actionable insights into workforce performance, employee engagement, talent development, diversity, attrition, recruitment effectiveness, and organizational health.
### 🎯 Key Outcomes
- Comprehensive visibility into workforce performance & organizational trends
- Predictive analytics to identify attrition risks & recommend retention
- Actionable insights into employee skills, learning & career development
- Monitoring of DEI metrics across organization
- Intelligent AI recommendations for workforce planning

- ## ✨ Key Modules Implemented

### 6. Dashboards
